# DreamPath AI
### Every learner deserves the chance to dream bigger.

**DreamPath AI** is an educational support and family-engagement platform designed to connect teachers, learners, and parents or guardians. It helps families stay involved in learners' academic journeys by making assignments, progress, learning gaps, and preparation for tests and examinations easier to understand.

🔗 **Live Demo:** https://khensanintombela.github.io/DreamPath/

## 🎯 The Problem

Parents and guardians may not always know what their children are learning, which assignments they need to complete, where they are struggling, or how prepared they are for upcoming tests and examinations.

DreamPath AI aims to bridge the gap between the classroom and home by providing a shared space for academic support, progress monitoring, and future career exploration.

## 💡 The Solution

DreamPath AI brings together three key users:

- **Teachers:** Create, edit, and delete assignments and provide structured academic support.
- **Learners:** View assignments, track completion, take practice quizzes, review subject progress, and explore careers.
- **Parents and Guardians:** Monitor assignments and academic progress and access practical suggestions for supporting learning at home.

## ✨ Key Features

### 1. Role-Based Dashboards
Switch between teacher, learner, and parent/guardian views to explore the platform from different perspectives.

### 2. Assignment Management
Teachers can create, edit, and delete assignments, including instructions, subjects, and due dates. Learners can mark assignments as complete or outstanding.

### 3. Learning Progress Tracking
View assignment completion, subject performance, quiz results, and topic-level progress using visual indicators.

### 4. Learning Readiness Checker
A rule-based demonstration that uses available topic scores to identify strengths, areas requiring revision, and suggested study plans before assessments.

### 5. AI Study Assistant Demonstration
Explore guided study suggestions, explanations, practice activities, and follow-up questions for different subjects.

### 6. Career Discovery
Explore example career pathways, identify relevant school subjects, save interesting careers, and set learning goals.

### 7. Parent and Guardian Support
View outstanding assignments, upcoming assessments, progress information, teacher feedback, and practical suggestions for supporting learning at home.

## 🛠️ Technologies Used

- HTML5
- CSS3
- Vanilla JavaScript
- Browser localStorage for demonstration data
- GitHub Pages for deployment

The prototype is designed to run directly in a web browser without requiring installation or a separate backend server.

## 🚀 Getting Started

### Use the live demo

Visit: https://khensanintombela.github.io/DreamPath/

1. Open the website.
2. Use the **View as** selector to switch between Teacher, Parent/Guardian, and Learner.
3. Explore the dashboards and available features.
4. Create or edit assignments, complete practice quizzes, check learning readiness, and explore career pathways.

### Run locally

1. Download or clone this repository.
2. Locate `index.html` in the project folder.
3. Open `index.html` in a modern web browser.

## 🧪 Demonstration Scope and Limitations

DreamPath AI is currently a functional front-end prototype using fictional demonstration data.

- The learning-readiness checker uses transparent, rule-based calculations; it is not a trained machine-learning model.
- The study assistant generates template-based guidance; it is not connected to a live AI model.
- Data is stored in the current browser using localStorage. It is not synchronised securely between separate users or devices.
- The dashboards use fictional learners, classes, scores, and assessment information.
- Authentication, a shared database, and production-grade privacy and security controls are not implemented in this prototype.

These limitations identify areas for future development rather than capabilities currently available in the demo.

## 🔮 Future Improvements

Potential future enhancements include:

- Secure user accounts and role-based access control.
- A shared database connecting teachers, learners, and parents or guardians.
- Integration with a live AI study assistant.
- Data-driven learning predictions and personalised recommendations.
- Notifications for assignments, upcoming assessments, and learners needing additional support.
- Expanded language and low-data accessibility support.

## 🌍 Vision

DreamPath AI aims to make educational support more visible, collaborative, and accessible by connecting what happens in the classroom with what happens at home—and helping learners see how their education can shape their future.
